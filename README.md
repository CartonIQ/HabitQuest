# 🌱 HabitQuest - Daily Habit Tracker

**HabitQuest** is a premium, 100% offline Android habit tracker with a warm minimalist UI, GitHub-style heatmaps, streaks, and RPG leveling.

## ✨ Features
- ✅ Create custom habits with emoji icons and colors
- 🔥 Streak tracking with fire emojis
- 📊 GitHub-style heatmap and weekly bar chart
- 🎮 RPG leveling system (Earn XP for completing habits)
- 🏆 Achievements & Milestones
- 📅 Daily reminders (WorkManager)
- 🌗 Full Dark/Light Mode
- 💾 Local Backup & Export (JSON)
- ⏪ Streak Freeze (Watch Rewarded Ad)
- 🔒 100% Offline & Private

## 🚀 Installation
1. Go to the **[Releases](https://github.com/CartonIQ/HabitQuest/releases)** page.
2. Download the latest `HabitQuest-Signed.apk`.
3. Open and install.

## 🛠️ Built With
- **Language:** Kotlin
- **UI:** Material 3, ViewBinding, Custom Glassmorphism
- **Architecture:** MVVM, Navigation Component
- **Local Database:** Room DB
- **Background Tasks:** WorkManager
- **Monetization:** Google AdMob
